# Quant build team roles

- **Quant Tech Lead**: overall architecture, file split, interfaces, implementation sequence.
- **Backtest Engine Builder**: event loop, portfolio, order handling, fill model.
- **Data Pipeline Builder**: data loading, cleaning, feature computation, caching/reproducibility.
- **Test & Reliability Owner**: tests, fixtures, regression checks, reproducibility notes.
- **Risk Review Engineer**: turnover limits, transaction costs, guardrails, failure handling.
