# 복붙용 프롬프트 모음

## 1. 라우터
```text
/route-task
나는 Claude Code가 처음이야.
지금 하려는 일은 [여기에 작업 입력].
어떤 팀을 써야 하는지 고르고, 필요하면 바로 시작해줘.
```

## 2. 퀀트 연구
```text
/quant-research
[전략 아이디어]
시장 직관, 데이터 요구사항, 검증 계획, 리스크까지 팀으로 검토해줘.
```

## 3. 퀀트 구현
```text
/quant-build
[구현 목표]
Require plan approval before any changes.
```

## 4. 공모전 기획
```text
/competition-design
[문제 분야 / 제약 조건]
주제 후보, 차별점, MVP 범위, 심사 포인트까지 정리해줘.
```

## 5. 공모전 발표
```text
/competition-pitch
[아이디어 설명]
발표 흐름, 슬라이드 구조, 예상 질문, 데모 시나리오를 짜줘.
```

## 6. 경제학 쉬운 설명
```text
/econ-explain
[질문]
초보도 이해하게 쉬운 비유부터 설명해줘.
```

## 7. 경제학 정책 분석
```text
/econ-policy
[정책 질문]
누가 이득/손해 보는지, 근거와 반대 논리까지 같이 정리해줘.
```

## 8. 바이브 코딩
```text
/vibe-build
[만들 기능]
Require plan approval before any changes.
```

## 9. 리팩터링
```text
/vibe-refactor
[리팩터링 목표]
Require plan approval before any changes.
```

## 10. 최종 검증
```text
/audit-final
[현재 결과물 요약]
치명적인 약점부터 순서대로 공격해줘.
```

## 11. 풀 파이프라인
```text
/full-pipeline
[작업 목표]
연구부터 구현, 최종 검증까지 순서대로 한 번에 진행해줘.
```

## 13. 너무 빨리 혼자 결론 내리면
```text
Wait for your teammates to complete their tasks before proceeding.
```

## 14. 끝났으면 정리

